subprocess.run是 Python 3 中用于执行系统命令的一个重要函数，提供了强大且安全的方式来运行外部程序或系统命令。它可以捕获输出、处理错误信息以及检查返回状态。

参数说明

args: 表示要执行的命令，可以是字符串或列表。推荐使用列表形式以避免 shell 注入风险，例如 ['ls', '-l']。

stdin、stdout、stderr: 定义子进程的标准输入、输出和错误流。可以设置为 subprocess.PIPE 捕获输出，或 subprocess.DEVNULL 忽略输出。

capture_output: 如果为 True，会同时捕获标准输出和标准错误，等价于将 stdout 和 stderr 设置为 subprocess.PIPE。

shell: 如果为 True，命令会通过操作系统的 shell 执行。注意使用时需防范安全风险。

cwd: 指定子进程的工作目录。

timeout: 设置命令的超时时间（以秒为单位）。超时后会抛出 TimeoutExpired 异常。

check: 如果为 True，当命令返回非零状态码时会抛出 CalledProcessError 异常。

encoding: 指定编码方式，用于将输出解码为字符串。

text: 如果为 True，标准输入、输出和错误会以字符串形式处理，而非字节形式。

env: 指定子进程的环境变量，默认为继承当前进程的环境。
