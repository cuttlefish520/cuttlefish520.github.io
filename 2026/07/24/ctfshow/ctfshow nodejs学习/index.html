1.什么是nodejs

Node.js就是一个在后端运行的JS代码

Node.js 是一个基于 Chrome JavaScript 运行时建立的一个平台。

Node.js 是一个事件驱动 I/O 服务端 JavaScript 环境，基于 Google 的 V8 引擎，V8 引擎执行 Javascript 的速度非常快，性能非常好。

1.1Node.js 的核心特点

1. 单线程事件循环

  • Node.js 使用单线程的事件循环模型
  • 通过事件驱动和回调函数处理并发请求
  • 避免了传统多线程编程中的线程切换开销

2. 非阻塞 I/O

  • 所有 I/O 操作（文件读写、网络请求等）都是异步的
  • 当等待 I/O 操作完成时，程序不会被阻塞，可以继续处理其他任务
  • 大大提高了应用程序的吞吐量

3. 跨平台

  • 支持 Windows、macOS、Linux 等多种操作系统
  • 一次编写，到处运行

4. 丰富的生态系统

  • npm（Node Package Manager）拥有数百万个开源包
  • 活跃的开发者社区

命令执行

nodejs是一个单线程的JS运行环境，如果想要执行一些命令或脚本程序需要用到child_process模块

这里就简单介绍几个child_process 子进程 | Node.js v26 文档

child_process.exec(command[, options][, callback]):生成一个 shell，然后在该 shell 中执行 command，并缓存任何生成的输出。

child_process.execFile(file[, args][, options][, callback]):child_process.execFile() 函数类似于 child_process.exec()，区别在于它默认不会启动一个 shell。相反，指定的可执行文件 file 会直接作为新进程启动，这使得它比 child_process.exec() 略微高效一些。

child_process.spawn(command[, args][, options]) 方法使用给定的 command 创建一个新进程，args 中提供命令行参数。如果省略，args 默认是一个空数组。它的返回是ChildProcess类 spawn(‘命令’, [‘参数’])

child_process.spawnSync(command[, args][, options])：child_process.spawnSync() 方法通常与 child_process.spawn() 相同，唯一的区别是该函数在子进程完全关闭之前不会返回。当遇到超时并发送 killSignal 时，该方法也不会返回，直到进程完全退出。如果进程拦截并处理了 SIGTERM 信号且没有退出，父进程将等待直到子进程退出。这里需要注意的是它的返回是数组，用**stdout.toString()**处理一下

child_process.execSync(command[, options])：child_process.execSync() 方法通常与 child_process.exec() 相同，唯一的区别是该方法在子进程完全关闭之前不会返回。当遇到超时并发送 killSignal 时，该方法不会返回，直到进程完全退出。如果子进程拦截并处理了 SIGTERM 信号而没有退出，父进程将等待直到子进程退出。返回Srting ,toString()处理

Nodejs原型链污染

先解释一下什么是原型链，在JS中，每个对象都有一个链接到被称为原型对象的一个链，就像java，python一样，所有类都会继承自最基础的Object类一样。在JS中，每一个对象都有一个内置属性，__proto__。

这属于对象自己的隐式原型，在往上继承的就是原生的Object.prototype，进行污染，污染的就是它。

这里可以看到，test1是空的，执行test1.__proto__.c=5这里会往上在Object.prototype里添加c这个属性。在JS里对象引用属性时，会一点点往上去找。需要注意的是test里写的__proto__其实并不是所说的隐式原型，就是一个简单的字面量属性。

通过属性赋值，这样就完成了污染。

字面类型对象

这些都是直接继承Object.prototype

obj → Object.prototype → null

用new function(){...}
