什么是Fastjson

Fastjson 是一个由阿里巴巴开发的 Java 库，用于将 Java 对象转换为 JSON 格式，或将 JSON 字符串转换为 Java 对象。

它提供了 toJSONString() 和 parseObject() 方法来将 Java 对象与 JSON 相互转换。调用toJSONString()方 法即可将对象转换成 JSON 字符串，parseObject() 方法则反过来将 JSON 字符串转换成对象。

Fastjson通过getter/setter来获得变量，如果public变量，会直接获取

Fastjson还提供了@JSONField来注释，它可以配置在变量和getter/setter上。
