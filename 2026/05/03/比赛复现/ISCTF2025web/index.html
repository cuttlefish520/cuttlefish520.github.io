preg_quote

preg_quote() 是 PHP 中用于转义正则表达式特殊字符的函数。它会在字符串中的正则表达式特殊字符前添加反斜杠，以确保这些字符被视为普通字符，而不是正则表达式的元字符。

把正则里的特殊符号（. * + ? | ( ) [ ] { } ^ $ \ /）转义成普通字符，防止恶意字符破坏正则语法。但它的第二个参数是可选的，一般默认是不会处理/，所以在第二个参数把/也传进去，让它也转义
